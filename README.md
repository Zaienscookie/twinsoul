## ✨ 核心功能

### 1. 长对话（多轮 + 双重结束判断）
- 由一方发起话题，另一方回应，形成自然的多轮对话
- 每轮对话最多 8 回合（可配置 `max_chat_rounds`）
- **规则兜底**：出现"晚安/睡吧/早点歇/明儿见"等结束语，或"嗯/好/行/哈哈"等短应承时，从第 2 轮起直接终止，不调 LLM，杜绝车轱辘话拉扯
- **LLM 智能判断**：聊够 3 轮后由 LLM 分析是否自然收尾（告别/应承/重复 → 终止；疑问/新话题 → 继续）
- **互斥锁**：同一时间只允许一个对话轮，定时/手动/插话并发触发时自动跳过，防止两边疯狂拉扯
- 对话间隔可配置（默认 90 分钟一次）

### 2. 定时随机问候
- 根据时段自动问候，模拟真人生活节奏
- 四个时段独立配置问候概率：
  - 🌅 早晨 6~9 点：起床问候
  - 🌞 中午 11~13 点：午饭问候
  - 🌇 傍晚 17~19 点：收工问候
  - 🌙 深夜 22~6 点：晚安问候
- 各时段可配置额外概率加成（`morning_boost` / `noon_boost` / `evening_boost` / `night_boost`）

### 3. 智能插话
- 有人在群里 @扎恩斯 或 @威廉 时，另一人概率性接话
- 消息内容提到"扎恩斯"或"威廉"时也会触发
- 插话概率可配置（默认 30%）
- 可随时开启/关闭

### 4. 上下文记忆
- 自动保留最近 N 轮对话历史（默认 5 轮）
- 双方记忆同步更新
- AI 知道之前聊过什么，对话更连贯
- 记忆持久化到 `context_memory.json`

### 5. 人格设定（严格遵循文件）
- **扎恩斯**：埃内斯特·扎恩斯夫斯基，43岁，白虎兽人
- **威廉**：埃内斯特·威廉夫斯基，扎恩斯的哥哥，46岁，白虎兽人

### 6. 回复延迟（真实感）
- 双子不会"秒回"：收到消息后随机延迟一段时间再回复，模拟"没立刻看到消息"
- 延迟范围可配置（`reply_delay_min` / `reply_delay_max`，默认 0.5~2 分钟）
- 手动触发对话/问候同样生效，更像真人

### 7. 睡眠阈值（不熬夜）
- 设定睡眠时间窗（`sleep_start_hour` / `sleep_end_hour`，默认 23:00~7:00）
- 睡眠时间内双子**默认休息**：不发起对话、不问候、不插话
- 支持概率性熬夜：`sleep_talk_chance`（默认 15%）让他们偶尔深夜还清醒
- 手动 `/ts 对话` / `/ts 问候` 仍可强制触发（`force`）

### 8. WebUI 管理面板
- 管理页面路径：`/pages/twinsoul/`
- 功能：开启/关闭插件、手动触发对话、手动触发问候
- 查看对话历史、上下文记忆
- 实时状态显示（运行状态、Bot状态、睡眠状态、历史/记忆条数）
- 一键清空历史/记忆
- 全部参数可视化配置

### 9. 更多功能
- 全部参数可调（WebUI 或 `/ts 设置` 命令）
- 对话历史持久化（`chat_history.json`）
- 支持指定话题对话（`/ts 对话 <话题>`）

## 🚀 快速开始

### 安装
将插件目录放入 AstrBot 的 `data/plugins/` 目录下，重启或重载插件即可。

### 配置
编辑 `config.yaml` 或通过 WebUI 配置：

```yaml
group_id: ''                     # 群号
zaiens_qq: ''                   # 扎恩斯QQ
william_qq: ''                  # 威廉QQ
zaiens_persona: '111'          # 扎恩斯人格标识
william_persona: 'Ｗilliam'    # 威廉人格标识
chat_interval_minutes: 90      # 对话间隔（分钟）
context_rounds: 5              # 记忆上下文轮数
max_chat_rounds: 8             # 单次最长对话轮数
greeting_enabled: true         # 启用问候
greeting_chance: 35            # 问候触发概率（%）
interject_chance: 30           # 插话触发概率（%）
morning_boost: 25              # 早晨问候额外加成
noon_boost: 20                 # 中午问候额外加成
evening_boost: 20              # 傍晚问候额外加成
night_boost: 15                # 深夜问候额外加成
william_initiate_chance: 55   # 威廉发起对话概率
reply_delay_min: 0.5            # 回复最短延迟（分钟）
reply_delay_max: 2.0            # 回复最长延迟（分钟）
sleep_start_hour: 23            # 入睡时段（时）
sleep_end_hour: 7               # 起床时段（时）
sleep_talk_chance: 15           # 睡眠时段熬夜概率（%）
```

### QQ 指令

| 指令 | 说明 |
|------|------|
| `/ts` | 查看帮助 |
| `/ts 开启` | 启动定时对话 + 问候 + 插话（同时解除急停） |
| `/ts 关闭` | 停止所有定时任务 |
| `/ts 停止` / `stop` / `急停` | **急停**：立即终止当前对话轮 + 停定时循环，急停后插话也不触发 |
| `/ts 对话 [话题]` | 手动触发一轮对话（可绕过睡眠强制触发，同时解除急停） |
| `/ts 问候` | 手动触发一次问候（可绕过睡眠强制触发，同时解除急停） |
| `/ts 重置` | 清空上下文记忆 |
| `/ts 状态` | 查看当前运行状态 |
| `/ts 设置 <key> <value>` | 修改配置参数 |

## 🔧 技术细节

### 长对话流程
```
发起者说话 → 对方回应 → LLM判断是否继续 →
  → 继续：对方再回应 → LLM再判断 ...
  → 结束：保存历史，等待下一轮
```

### 回复延迟逻辑
- 每次发言（对话、问候、插话）前都会调用 `_simulate_reply_delay()`
- 在 `reply_delay_min` ~ `reply_delay_max` 分钟之间取随机值，模拟"没立刻看到消息"

### 睡眠阈值逻辑
- `is_in_sleep_window()`：判断当前是否位于睡眠时间窗（支持跨天 23:00~次日 7:00）
- `wants_to_sleep()`：窗口内按 `sleep_talk_chance` 随机决定今晚是否熬夜
- 定时循环、问候、插话在"应该休息"时自动跳过
- 手动 `/ts 对话` / `/ts 问候` 传入 `force=True` 可强制唤醒执行

### 结束判断逻辑
1. **急停优先**：收到 `/ts 停止`（急停）后，当前对话轮立即终止，定时循环停止
2. **规则兜底**：`is_closing_line()` 检测结束语（晚安/睡吧/早点歇/明儿见等）与短应承（嗯/好/行/哈哈等），从第 2 轮起直接终止，不调 LLM
3. **LLM 智能判断**：聊够 3 轮后调用 LLM 分析最后一句话是否在自然收尾（告别/应承/重复 → 终止；疑问/新话题 → 继续）
4. **互斥锁**：同一时间只允许一个对话轮，并发触发自动跳过，防止拉扯
5. **最大轮数限制**：到达 `max_chat_rounds` 后强制结束
6. **空回复保护**：AI 不回复时自动终止
7. **状态日志**：`debug_log` 开启时，每轮输出 `状态判定(规则/LLM): 「内容」→ 终止本轮对话 / 继续回复`，急停输出 `⛔ 收到急停 → 终止本轮对话`

### 数据持久化
- 对话历史：`chat_history.json`（所有对话记录）
- 上下文记忆：`context_memory.json`（双方各自保留最近记忆）
